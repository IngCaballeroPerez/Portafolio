INDUSTRIAL / MES

M.E.S — Industrial Manufacturing Execution System

Multi-business MES for plant operations: centralised identity, permissions and audit, a Python-served web interface, and a design canvas kept in sync with the repository. Ten active businesses run on the same base.

  • Python
  • SQLite / Oracle
  • HTML·CSS·JS
  • PLSQL
Learn about the project
The challenge
An industrial MES that runs on Windows with no prior installation, centralised control of users, permissions and audit per business, and a decoupled architecture that allows future Oracle integrations without blocking the pilot.
My contribution
Architect, full-stack developer and release owner: SQLite Control Plane, Python backend (auth, authorisation, Root recovery), web interface (hierarchical menu, requests, approvals, MES Config), synced design canvas and Oracle scripts generated without manual editing.
Technical decision
Separate design artefacts (canvas.json, .dc.html) from runtime code in a satellite repository with two-way repo-to-canvas sync, so the decision plan and the screens evolve without breaking the pilot.
Result or takeaway
Ten active businesses, real login/logout with mandatory password change, supervisor-to-ADMIN request flow, automated tests in CI/CD and a Windows Portable package with embedded runtime.

TOOLS / AI

Knight-Plugin 4.3

Engineering plugin for Claude, Codex and Qwen that coordinates seven specialised agents with on-demand loading of seventeen specialties, configurable verification and persistent evidence.

  • JavaScript
  • Node.js ≥22
  • Python
Learn about the project
The challenge
Unify specialisation, verification and evidence without duplicating configuration across Claude, Codex and Qwen; remove manual checks and automate recovery of interrupted runs.
My contribution
Designed the seven-agent plus seventeen-specialty framework, configurable checks (quick/extended), a lock and recovery system by PID, per-environment adapters and deterministic packaging with SHA-256.
Result or takeaway
Working plugin in Claude Code, Codex and Qwen with no npm dependencies; confirmed recovery of interrupted runs and a deterministic ZIP package with a SHA-256 manifest.

03

DESKTOP APP

LocalChat v0.2.1

Fully local desktop messaging (no server, no internet) in Python/Tkinter with SQLite, built as an educational baseline for GUI optimisation and code comprehensibility.

  • Python
  • Tkinter
  • SQLite
Learn about the project
The challenge
Prove that a Tkinter GUI scales to many contacts without degradation: eliminate N+1 queries, repeated reconnections and redundant repaints.
My contribution
Redesigned the update pattern to a single query plus cache, a single SQLite connection with RLock and WAL, an in-memory EventBus for multiple windows, history debounce and receipt batching; documented every module.
Result or takeaway
No N+1 queries, multiple windows synced without a server, presence and message state computed without an extra column, and passwords hashed with scrypt (N=2^14).

02 / ABOUT ME

The person behind the code.

I am a programmer focused on turning real operational needs into solid systems. Although my goal is gameplay programming with Unreal Engine and C++, much of my work is building the systems, tools and pipelines that make teams — and games — run: identity and permissions, request workflows, agent orchestration and performance work.

I enjoy the problems that live at the intersection of design and engineering: how a screen stays clear under real data, how a tool stays intuitive, how a system scales without becoming fragile. I care about clean, maintainable code and about shipping things people can actually use.

How I work

I start by understanding the real need, choose the simplest solution that holds up, and verify it works before moving on. I iterate in small, testable steps, keep design and runtime separated, and leave the code readable for the next person — including future me.
