    // Habilidades

    Mis pilares

    De la planificación al mantenimiento: mi forma de desarrollar aplicaciones.

    1. 01

      Arquitectura y planificación

      Organizo aplicaciones en componentes y defino su estructura, flujo de datos y requisitos para facilitar su evolución.

      Tecnologías y herramientas
      Markdown, Mermaid, GitHub Issues

    2. 02

      Diseño UI/UX

      Diseño interfaces claras y accesibles, con navegación intuitiva y adaptación a diferentes pantallas y formas de interacción.

      Tecnologías y herramientas
      Figma, SVG, herramientas de accesibilidad del navegador

    3. 03

      Frontend e interfaces

      Desarrollo interfaces interactivas para aplicaciones web y de escritorio, cuidando su presentación y facilidad de uso.

      Tecnologías y herramientas
      HTML5, CSS3, JavaScript, Tailwind CSS; Tkinter y ttk para escritorio

    4. 04

      Backend y lógica de aplicación

      Implemento reglas de negocio, validaciones y procesamiento de información en aplicaciones locales y servicios de servidor.

      Tecnologías y herramientas
      Python, C#, Java, Perl; Node.js para JavaScript en servidor

    5. 05

      Bases de datos y almacenamiento

      Organizo, consulto y almaceno información, con mecanismos de persistencia, importación y exportación.

      Tecnologías y herramientas
      SQLite, Oracle Database, IndexedDB, SQL, DBeaver; JSON para intercambio de datos

    6. 06

      APIs e integraciones

      Desarrollo y conecto APIs para intercambiar información entre aplicaciones y servicios, con contratos y documentación claros.

      Tecnologías y herramientas
      FastAPI, REST, GraphQL, OpenAPI, Postman

    7. 07

      Seguridad de aplicaciones

      Aplico controles de acceso y validación de entradas para proteger la información y reducir vulnerabilidades comunes.

      Tecnologías y herramientas
      OWASP ZAP, herramientas de desarrollo del navegador, bibliotecas de autenticación y validación

    8. 08

      Pruebas y calidad

      Verifico funciones y recorridos de usuario, reproduzco errores y reviso compatibilidad y rendimiento.

      Tecnologías y herramientas
      pytest, unittest, Playwright, Chrome DevTools

    9. 09

      Empaquetado y publicación

      Preparo ejecutables y paquetes de distribución, y automatizo procesos de compilación y publicación según la plataforma.

      Tecnologías y herramientas
      PyInstaller, .NET CLI, GitHub Actions, Docker

    10. 10

      Mantenimiento y automatización

      Corrijo errores, mantengo versiones y automatizo tareas repetitivas, incluido el procesamiento de archivos y datos.

      Tecnologías y herramientas
      Git, GitHub, VS Code, Python, Batch, CMD, pandas
